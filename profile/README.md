# GrupoMO

Organización del grupo empresarial **Otazu** y **Maploca**.

Reunimos el trabajo digital y el conocimiento operativo de las dos empresas:
plataforma, datos, seguridad y procedimientos internos. Trabajamos con Git y
GitHub como estándar de la industria para versionar, revisar y conservar lo que
sabemos.

## Qué hacemos

- Plataforma digital y datos.
- Seguridad y gobierno de la información.
- Conocimiento y procedimientos internos de cada empresa.

## Repositorios

Los repositorios de conocimiento son **privados** y el acceso se gestiona por
equipos:

- `otazu-knowledge` — procedimientos y skills de Otazu.
- `maploca-knowledge` — procedimientos y skills de Maploca.
- `shared-knowledge` — métodos y plantillas comunes, revisados por ambas.

Cada empresa conserva su contenido. El repositorio compartido no contiene datos,
sistemas ni precios de una empresa concreta.

## Seguridad

Si has encontrado una vulnerabilidad en alguno de nuestros sistemas, **no abras
una issue pública**. Sigue el procedimiento de
[SECURITY.md](https://github.com/Grupo-MO/.github/blob/main/SECURITY.md).
